# 角色美术生成标准

新增、重绘或替换游戏角色时，遵循本文件，不要只生成一张概念图后就结束。先核对角色设定和游戏中的实际用途，再保留可追溯的参考图、提示词、原图和导出图。

## 画风与比例

- 统一采用写实厚涂油画插画。保留可见的手绘笔触、清晰的明暗体积、耐寒衣物的材质层次和克制的冬季低饱和配色。
- 成年人按约 7 至 7.5 头身绘制，头部、手掌、靴子保持自然尺寸，腿部要有清楚的大腿和小腿长度。拒绝大头、短腿、Q 版、像素画和塑料感 3D。
- 儿童、动物和感染者按其物种与年龄保持可信比例，不套用成年人的身高比例。
- 角色缩到游戏中的实际显示尺寸后，仍需看清脸部朝向、衣物层次和主要装备。轮廓不能被背景、光晕或无关道具吞掉。

## 阿列克谢设定基准

- 保留圆框眼镜、冬帽、棕色背包和卷起的毯子。
- 采用腰长的旧棉工装夹克、围巾、打补丁的工装裤、系带冬靴和实用腰带。
- 阿列克谢是铁路货运调度员兼冬季探险者，不画成法官、神职人员或全副武装的军人。
- 当前比例稿在 `generation_runs/2026-11-16/aleksei_master_proportion_review.png`。它可作本轮重绘的比例与画风参照。已有运行时精灵表只作布局和身份核对，不要沿用其中被指出头大腿短的比例。

## 对话胸像

- 对话肖像采用 512×512 像素。先生成同一角色的 2×2 情绪图：左上平静、右上悲伤、左下坚决/激动、右下苦笑。四格保持脸型、年龄、服装、镜头和背景一致。
- 已有的本角色肖像只约束身份，阿列克谢基准只约束油画笔触和完成度。
- 使用 `tools/art_gen/process_portrait_atlas.py` 切图，输出 Calm、Sad、Intense、Wry。处理器另留一份 Calm 默认别名供本次运行归档；只有游戏原本就有或明确引用 `PRT_<name>.png` 时才替换它，避免新增未引用资源。

## 角色动作图的运行时规格

- 当前角色动作图为 864×336 像素，RGBA，12 列×3 行；每格 72×112 像素。
- 方向行依次为南、东侧、北；西侧由游戏翻转东侧得到。
- 列语义必须先从对应角色脚本核对。通用部分是 c0 待机、c1–8 行走循环；c9–11 为角色专属姿势。现有角色分别是：阿列克谢蹲伏/蹲行，OSK 举枪瞄准/搜索低持/倒地，狂犬蓄力/前扑/倒地，半人半狼蜷缩/硬直/倒地。
- c9–11 的方向专属姿势需在南、东、北三行保持一致，避免转向时姿势跳变；倒地帧也在三行共用。
- 帧锚点为 (36,108)，脚底对齐；透明背景和单格边界必须干净，不能串格。
- 不改文件名、路径、帧布局或锚点来做纯美术替换。改动引擎契约前先查 `NightPlayer.gd`、`Campaign.gd`、场景 Sprite2D 设置和 `tools/art_gen/check_chars.py`。

## 生成与验收流程

1. 查角色的剧情设定、阵营、年龄、动作图或胸像的实际引用点，并查看现有导出规格。
2. 为角色准备与用途匹配的基准稿。身份参考图只约束身份和装备，阿列克谢基准只约束画风与完成度，不把阿列克谢的脸或衣服复制给其他人。
3. 本项目当前图像生成入口是 Codex `image_gen`。动作角色先生成全身基准，再参考它绘制动作表。仅出现在剧情中的角色用身份肖像作为基准，再绘制情绪图。生成动作表时，已有动作表只作格位、帧顺序和姿势参考。每个角色要有独立身份稿，不能把多名角色塞进一张图。
4. 保存原始生成结果、完整提示词和工具路由信息到 `generation_runs/YYYY-MM-DD/<character>/`。筛掉脸、装备、肢体比例、格位或方向错误的版本后再导出。
5. 保持 864×336、12×3、72×112、RGBA 和 (36,108) 锚点。检查每一行的方向一致、循环帧接缝、脚底线、轮廓、透明边缘以及游戏实际尺寸的可读性。
6. 将导出图放回现有资源路径；纯美术更换不改角色碰撞、AI、移动速度、受击框或剧情逻辑。完成后记录更换资源范围、运行时影响和未通过项。

当前 `generation_runs/2026-11-16/doctor.json` 记录了可用的图像路由和能力检查。本轮确认没有可用的视频生成路由，所以动作图沿用项目已采用的整张精灵表生成与切图方式，不应声称生成了图生视频动画。

## 伙伴与独立 NPC 小立绘

- 安娜、阿什、古莉娅、伊万、帕维尔的伙伴图保持项目原尺寸：人类角色 72×112，阿什 96×80；保留既有文件名、路径和脚底基线。
- 伙伴动作板使用单角色 2×2 透明图：左上站立、右上步态 A、左下步态 B、右下备用姿势。身份和服饰参考该角色胸像及旧小立绘；风格继续使用自然比例的厚涂油画。
- 用 `tools/art_gen/process_partner_atlas.py` 裁切、统一缩放、脚底对齐并清理透明边缘。不得为适配新图改场景缩放或碰撞设置。
- 列昂诺夫、商人、幸存者等静态人物沿用各自旧资源尺寸和路径，只替换站立美术；不要从小图推测或新增剧情设定。
- 原始图、提示词、处理后图和处理 JSON 一起保存在 `generation_runs/YYYY-MM-DD/<character>/`。

### 伙伴八帧步态标准

- 每个伙伴交付 1 张站立帧和 8 张独立步行帧；不得只交付 2 帧循环。先生成单角色 2×2 透明主动作板（左上站立、右上步态 A、左下步态 B、右下备用姿势），再生成两张专用 2×2 步态板 A/B，每格都画不同的连续步伐。
- 使用 `tools/art_gen/process_partner_walkcycle_pair.py` 按 A0–A3、B4–B7 组合为 Walk0–Walk7。人类帧保持 72×112、脚底 y=108；阿什保持 96×80、脚底 y=76。保留现有运行时文件名、路径和碰撞/缩放设置。
- 提示词明确自然成人比例（约 7–7.5 头身、自然头手大小、清晰大腿/小腿比例）、角色专属衣着装备、厚涂笔触、低饱和冬季色和透明背景。身份图只约束身份衣着，画风参考只约束质感。
- 生成后查看编号联系表，逐帧检查姿势确实不同、朝向正确、脚底对齐、循环接缝、轮廓和透明 alpha；不能把白色预览底误判为透明。保留被拒候选及原因，再把通过的帧复制进运行时资源。
- 将每一次调用实际使用的完整提示词逐字写入角色运行目录，连同原图、身份参考、处理 JSON 和验收图归档。不要事后凭记忆把重写提示词标成原始提示词。
