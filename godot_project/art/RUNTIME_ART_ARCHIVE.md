# 游戏内美术资源接入

- 战役顶栏「美术档案」读取 `asset_manifest.json`，并纳入 `90_concept` 概念图，按类别分页加载视觉资源；每页最多加载 16 张缩略图，点击缩略图可放大查看。音频不作为图片显示。
- `80_maps` 下的完整地图图像也会被扫描加入地图类别。战役地点选择面板优先显示对应地点的 `map_night.png`，缺失时回退到 `map.png`。
- 原先保存在项目外的生成概念成图已复制到 `90_concept` 并单独登记；用户参考图不纳入运行时档案。
- 新生成的 fear / determined / hurt 肖像可以直接用于剧情台词情绪标记；现有 calm / sad / intense / wry 资源选择保持不变。
- 过场 CG 备选和道具变体可以在档案内逐张检查。没有被指派到具体故事页或关卡节点的图仍作为可复用资源留在档案，不会被自动塞入碰撞地图。
