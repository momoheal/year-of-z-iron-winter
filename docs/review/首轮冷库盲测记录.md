# 602 室与四号冷库首轮试玩记录

已收到的玩家反馈与后续复测入口见 [《凛冬铁轨》实际试玩记录](实际试玩记录.md)。下表用于按新档、玩家和路线记录单轮盲测。

每位玩家单独记录一次。使用 Windows 工作区的 launch_game.bat，从新档开始，回到 602 并看完回家反馈时停止计时。使用独立测试账户或空存档环境，避免覆盖个人进度。20–30 分钟是待验证的目标。

给玩家的一句话：“请按你自己的想法玩到第一次回家。卡住时可以说出你正在找什么。”主持人先让玩家自己决定路线，记录必须介入的位置和原因。

| 观察项 | 本次记录 |
| --- | --- |
| 测试日期、版本或工作区快照、玩家是否玩过潜行游戏 | |
| 出门前，玩家认为今天要做什么？记原话 | |
| 何时发现封存箱？是否有空位？是否读到另一条路线？ | |
| 选择撤离或绕行时，玩家担心失去什么？ | |
| 结算原因、实际带回的透析液袋数、是否查过北雨棚 | |
| 回到 602 后问“这一趟带回了什么？关于拉娜，你现在知道什么？”记原话 | |
| 总用时、首次卡点、主持人提示次数 | |

若玩家错过绕行提示，记下当时正在看什么。若玩家选择直接回家，能解释担心药带不回来，也算理解了取舍。把界面上实际显示的内容与玩家的解释分别记下。
