# 《Z年纪事：Iron Winter》探索 Demo 设计文档

- **版本**：2026-10-22（街区草图生成器版）
- **文件**：`prototypes/Year_of_Z_Iron_Winter_Exploration_Demo.html`（单文件，零构建，Canvas 2D）
- **在线体验**：https://momoheal.github.io/year-of-z-iron-winter/prototypes/Year_of_Z_Iron_Winter_Exploration_Demo.html
- **定位**：Godot 为主线，HTML Demo 为设计草稿——先在 HTML 里把新点子玩通、验通，再落到 Godot 的 Novorsk-17 第一关实景。

## 1. 定位与核心循环

玩家在雪夜里的废墟街区行动一夜（250 真实秒，22:00–05:00）：

**进街区 → 找掩护 → 搜刮容器与尸体 → 躲清杀兵 / 杀狂暴者 → 保暖回温 → 完成委托 → 活到天亮。**

核心张力有三条：视野（只能看见眼前一小片）、体温（越冷越要生火，火又暴露位置）、身份（半人不能误杀，清杀兵不能硬拼）。

## 2. 地图生成：美术先行

旧管线是反的：先用 BSP 随机切出一堆墙迷宫，再给每个墙格贴装饰——建筑永远只能是墙盒子，墙也永远占一半地图。本轮改成美术先行：**先画街区草图，再由草图长出可玩的格子。**

### 2.1 街道网

- 主横街 + 主竖街（4–5 格宽）+ 满幅支路（3 格宽，2–3 条），全部离边界 ≥2 格，不切断边界环。
- 支路必须满幅：横向支路贯通整宽，纵向支路贯通整高。教训：支路只画一半时，分区仍按整条带算，另一半会留下一条“影子墙带”，把扇区隔断。
- 同向街道带之间至少留 4 格空隙，保证扇区能成形。

### 2.2 扇区

街道带之间的矩形空地（≥4 格）即为扇区；每个扇区就是一个空地房（房间矩形 = 整个扇区）。

- 空地房带机制（随机）：储藏室 / 冷库 / 暗室 / 厨房 / 诊所 / 巡逻区 / 机修车间 / 无。
- 房中心不在扇区中心定死：楼和楼块放完后，从扇区中心螺旋找一块干净空地（是地板、不在楼内）当房中心——出生点和重生点永远站在干净地板上。

### 2.3 楼

- **实心楼**：每扇区 1–2 栋，5–9 × 4–6 格。内部格画整片屋顶，边缘格画立面 + 窗（有亮窗有暗窗），楼从此是一整栋，不再是墙盒子。
- **可进楼**：每图 1–3 栋。内室 5–7 × 4–5 格，外圈一格墙，配一扇锁着的门（BDOOR）。
  - 门只开向街道：门外侧一格必须落在街道上。街道网本身连通，门外侧永远够得着，也符合建筑临街开门的逻辑。
  - 内室 + 墙圈 + 门全部进保护集：连通修复不得凿穿楼墙，也不得封掉楼内。
  - 屋顶平时盖着：没见过门时只画淡淡剪影，见过门才画实；进楼或站在门口时掀开。
- 清杀兵、巡逻路径点、半人、NPC 不在楼内生成；狂暴者可以藏在楼内。

### 2.4 边界

外圈按 6–13 格分段，约 55% 建筑段（墙，画成整栋 + 亮窗）/ 45% 围墙段（栅栏：密立柱 + 两道横杆 + 顶部斜刺铁丝网）。边界环开局即已知：小地图一开局就有一圈边（建筑段深灰、围墙段浅灰）。

### 2.5 环境与容器

- 雪泥 / 掩体 / 铁丝网 / 走廊门，全部有守则：不铺房中心格（出生/重生站位）、不铺临街一格（扇区出口）、不铺门外侧一格、不进楼内。
- 容器类型：木箱、储物柜、药柜、冷柜、公文包、保险柜、暗格、废弃汽车、垃圾堆、补给箱、尸体。
  - 偏向：楼内用冷柜/储物柜/药柜/公文包；室外用废弃汽车/垃圾堆/补给箱；厨房、诊所、机修车间、储藏室各有偏向；冷柜只出现在楼内。
- 尸体掉落（搜刮时按死者身份分表生成）：狂暴者出杂物/食物/保暖物；清杀兵出零件/武器/药品/贵重品；半人出食物/贵重品/药品。

### 2.6 连通性保证

- **放时检查**：每放一栋楼、一个楼块，就用 sectorConnected 检查该扇区空地是否还连着街道，断了立刻撤销换位置重放。
- **生成后修复**：ensureConnected 从入口洪水填充，孤岛用 L 形走廊接回入口（跳过保护集），仍不可达的死区封成墙并剔除其中容器。
- **验证数据**（20 个随机种子实测）：墙占比 17.5–24.8%（平均 21.7%，旧 BSP 版约 50%）；可达面积 68–76%（平均 72.1%）；每图 2–3 栋可进楼；屋顶格 154–302；空地房中心、楼门外侧、空地容器全部可达；冰箱只在楼内；清杀兵/NPC/半人不在楼内。

## 3. 瓦片与渲染

瓦片类型：FLOOR（空地）、WALL（墙/楼）、SLUSH（雪泥）、COVER（掩体）、FENCE（铁丝网）、DOOR（走廊门）、WEDGED（卡死的门）、BDOOR（锁着的楼门）。

渲染规则：

- 楼块内部格（四邻皆墙）画整片屋顶；边缘格画立面 + 窗；边界建筑与围墙同理。
- 可进楼屋顶由 drawRoofs 在雾之后单独画：未见门画 0.5 透明剪影，见过门画实，进楼或站门口不画。
- 斜俯视：每米 38 像素（按 -/= 缩放 26–72），y 轴压缩 0.62（75 度斜俯视近似），墙体挤出高度 0.62。
- 程序化美术（无外链图，全嵌在 HTML 里）：逐格哈希细节（地面裂纹/车辙/雪点、墙顶积雪/裂缝/管线）、血渍（上限 40 处）、人物（玩家兜帽派克大衣 + 背包、僵尸破衣红眼前伸手臂、清杀兵战术背心头盔步枪、半人佝偻苍白、NPC 宽檐帽/臂章）。

## 4. 视野与雾

- 主视野 90 度锥，视距 12 米；眼镜裂后 7.2 米；暗室 ×0.65。
- 近身感知 1.8 米：这个距离内不论朝向都感知到。
- 环形视野：身边 5×5（2 格）一圈不论朝向都可见，但照样受墙遮挡；圈外仍需视野锥。
- 视线判定（losClear）：目标格本身不算遮挡；敞开门洞能看穿；卡死的门仍挡；墙作中间格仍挡。
- 雾：已探索的格子留暗色记忆，未探索全黑；边界环开局即已知。
- 小地图：只画已探索格，颜色区分墙、围墙、门、雪泥。

## 5. 角色、敌人与战斗

玩家：血量 100、体力 100、体温 100。速度：走 3.2 / 潜行 1.6 / 疾跑 5.0 米/秒。噪声半径：走 2.5 / 潜行 0.8 / 疾跑 7.5 / 挥砍 1.6 / 搜刮 3.2 / 扔罐 9 / 枪声 25 米。

武器：

| 武器 | 伤害 | 射程 | 特点 |
| --- | --- | --- | --- |
| 赤手 | 8 | 0.9 | 打不退狂暴者，只能推开 |
| 铸铁道钉撬棍 | 34 | 1.3 | 可卡门 15 秒；弯头可把饭盒推进 12cm 门缝 |
| 东街生锈砍骨刀 | 46 | 1.0 | 正面重劈狂暴者 100% 卡入锁骨缝，1.5 秒内连按 6 次拔刀 |
| 改装双管猎枪 | 95 | 9 | 散射角随心率扩张；枪声惊动全图清杀兵 |
| 莫辛纳甘步枪 | 150 | 18 | 一枪一台阶，拉栓慢，声音传得比风雪还远 |

敌人：

- 狂暴者（60 血）：咬击；蛮兽变种（150 血，慢速重击）。
- 清杀兵（120 血）：成对巡逻，共享路径点；suspect/lock 两段 AI；枪击。
- 半人（40 血）：蹲伏，误杀有代价；安娜可直接标注其状态。
- 尸体：击杀后留倒地尸体，靠近按 E 搜刮（按死者身份分表）。

打击感：击退（狂暴者 0.6 / 清杀兵 0.35 / 蛮兽 0.25 米）+ 命中顿帧（0.045 秒，击杀 0.09 秒）+ 震屏 + 飘伤害数字。玩家与敌对实体、敌对实体之间有分离碰撞（0.75 / 0.7 米），咬击距离 1.15 米不受影响。

伙伴：灰烬（灰狼犬，6 米内嗅觉预警标出容器/生物，三态叫声分辨狂暴者、半人、求救者）；安娜（辨认半人，背包 +4 格）。

## 6. 生存与夜

- 一夜 250 真实秒；地点寒冷系数 0.4–1.3。
- 雪泥：移速 ×0.65，噪声 ×2.0。
- 火堆可回温；厨房自带火堆；冷库房体温流失 ×1.6；诊所首次进入 +25 血。

## 7. NPC 与委托

- 黑市贩子老周：背包 1 换 1。要伏特加/手表/磁带/玻璃，换绷带/阿司匹林/黑麦面包/罐头/水。
- 避难所联络员：取物 / 猎杀 / 救援三类委托，接时记录基线（已杀数/已救数），完成奖励进背包。

## 8. 操作

桌面：WASD 移动，鼠标瞄准，点击攻击，按住 E 交互（开锁门 0.8 秒、撬棍卡门 15 秒），G 扔罐，Q 喝水，F 绷带，R 换弹，Shift 疾跑，Ctrl 潜行，-/= 缩放视野。

触屏：左下虚拟摇杆走路，手指滑动瞄准，右下按钮（攻击 / 按住交互 E / 扔罐 / 喝水 / 绷带 / 换弹 / 疾跑与蹲伏开关 / 视野 +/-）；朝向跟随移动（0.4 秒内手指瞄准优先）；画面禁双指缩放。

## 9. 地点系统

13 个节点（如第 3 居住区锅炉房后巷、城北四号铁路冷库、夜间广轨货场、铁道下穿积冰道等），每个节点有难度、种子、寒冷系数、掉落偏向、限时与剧情。种子 = 节点种子 ×3 + 天数；节点剩余战利品跨夜保留。

## 10. 工程与验证

- 单文件、零构建；种子随机（mulberry32），同种子同图。
- Node 桩 harness（DOM Proxy 桩、覆写音效）实跑 startScene / update / draw 冒烟与断言：结构、连通、墙占比、楼密封、边界、容器偏向、生成位置、尸体分表、屋顶显隐、环形视野、隔门近战。
- 与 Godot 线的关系：HTML 只做设计草稿，验证通过的点子（视野、楼机制、打击感、委托）再落到 Godot 主线。
