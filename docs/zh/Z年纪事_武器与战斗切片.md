# Z年纪事 · 武器与战斗切片（撬棍 / 枪械）与灰盒美术扩展

> P5 切片说明。对应代码：`godot_project/scripts/night/Arsenal.gd`、`NightExplore.gd`（战斗段）、
> `NightSoldier.gd`（可击杀）、`NightOverlay.gd`（战斗读数）、`tools/art_gen/gen_weapons.py`。
> 测试：`godot_project/tests/night_combat_smoke.gd`。
>
> ⚠️ 本沙箱里没有 Godot 引擎，**这份代码还没有在装引擎的机器上首跑过**。所有数值都经过静态推演与
> 数据层断言，但手感（射速、散布、噪声半径）需要在实机上按下面「验收」一节跑一遍。

---

## 一、这一轮解决的两个问题

1. **主角只会潜行，不会还手。** 夜潜里遇到狂暴者只能跑、遇到清杀队只能绕；撬棍在剧情里挥舞过
   （灭口抉择），但玩家手上没有真正的攻击手段。
2. **「别的灰盒」还是空的。** 货场（yard）有美术，西站调车场（marshalling）和松林庄园（manor）
   虽然地形齐了，但除了地形与原有道具，没有任何「打起来能用的东西」，也没有让玩家想冒险的理由。

对应地做了两件事：一套能打的手感（撬棍 + 三支枪），一批新的程序化资产（武器 / 弹药 / 哨位道具 /
战斗 VFX），并把它们摆进另外两张图。

## 二、美术：新资产与生成方式

`tools/art_gen/gen_weapons.py`（新文件，13 件资产，全部走原有 `artlib` 管线）：

| 资产 | 用途 | 尺寸 / 锚点 |
|---|---|---|
| `PRP_Crowbar_Rail` | 铸铁道钉撬棍（手里 / 世界） | 108×82，pivot 底中 |
| `PRP_Pistol_TT` | ТТ-33 手枪 | 104×68，pivot 握把 |
| `PRP_Rifle_Mosin` | 莫辛纳甘步枪 | 208×48，pivot 扳机处 |
| `PRP_Shotgun_Sawn` | 截短双管猎枪 | 132×58，pivot 握把 |
| `PRP_Ammo_Box_Open` | 掀开的弹药箱（可搜刮，必出步枪弹） | **58×47（≈0.9m）** |
| `PRP_Sandbag_Line` | 沙袋掩体（layer 2：蹲下挡视线） | 208×118（≈3.2m） |
| `PRP_WeaponRack` | 武器架 | **96×94（≈1.5m）** |
| `PRP_Target_Silhouette` | 木靶人（灰盒标定 / 射击场） | **77×127（≈1.2m）** |
| `VFX_MuzzleFlash_Sheet` | 枪口焰 4 帧（hframes=4） | 384×96 |
| `VFX_Bullet_Tracer` | 曳光 | 128×16 |
| `VFX_Impact_Spark` | 弹着火星 | 64×64 |
| `VFX_Shell_Casing` | 弹壳 | 22×12 |
| `VFX_Blood_Mist` | 血雾 | 72×72 |

**尺寸纪律**：1 逻辑米 = 64 px。世界道具必须按真实尺寸出图（弹药箱 0.9m、枪架 1.5m、靶板 1.2m），
所以这四个函数末尾用 `_fit()` 把画稿等比缩到目标宽度并同步缩放 pivot；握在手里的武器则故意放大
（2~3 倍）以便在 64px/m 的世界里看得清，由 `Arsenal` 的 `scale` 在引擎里缩回来。

**只出新的，不动旧的**：新开了一个 `weapons` 步骤，而不是重跑 `props`/`vfx`。
原因是 PIL 版本差异会让「重跑出来的旧资产」出现肉眼看不见、但字节不同的差异，而仓库要求
yard 的地面与立面逐像素不变。

```bash
cd godot_project/tools/art_gen
python gen_assets.py --level yard weapons        # 只出 P5 的 13 件
python gen_assets.py --level marshalling weapons
python gen_assets.py --level manor weapons
python build_scene.py --level marshalling        # 新增道具 → 重建场景
python build_scene.py --level manor
python check_levels.py                           # 必须 PASS
```

## 三、军械库：四件家伙

`scripts/night/Arsenal.gd` 是唯一数据源（伤害 / 射速 / 噪声 / 散布都在这里调，逻辑不许再抄一份）。

| id | 名称 | 类型 | 伤害 | 射速 | 弹匣 | 备弹 | 噪声 | 射程 | 散布 |
|---|---|---|---|---|---|---|---|---|---|
| `crowbar` | 铸铁道钉撬棍 | 近战 | 34 | 1.45 次/s | — | — | 4.5 m | 1.9 m（±0.85 rad） | — |
| `pistol` | ТТ-33 | 半自动 | 42 | 3.6 发/s | 8 | 16（上限 32） | 26 m | 16 m | 2.6° |
| `rifle` | 莫辛纳甘 | 单发 | 96 | 1.05 发/s | 5 | 10（上限 25） | 44 m | 28 m | 1.1° |
| `shotgun` | 截短双管 | 单发 | 15×6 弹丸 | 1.15 次/s | 2 | 8（上限 20） | 38 m | 9.5 m | 7.5° |

撬棍的伤害与 `CampaignData.WEAPONS` 里那条 `crowbar`（34）对齐 —— 战役层与实战层不许各说一套。

**开场带什么**

* 撬棍永远在手上（1 号槽）。
* 战役里：按 `cfg.weapon`（`best_weapon()` 的结果）映射，`mosin → rifle`、`shotgun → shotgun`、
  `cleaver / crowbar / fist → crowbar`；另外固定配一支 ТТ（缴获的底牌）。
* F2 独立跑灰盒：撬棍 + ТТ + 莫辛，方便直接验收。

**弹药从哪来**：搜刮到 `ammo`（步枪弹）/ `bolt`（枪机）/ `part`（零件）会折算成备弹，见
`Arsenal.AMMO_FROM_ITEM`；两张新图都放了 `PRP_Ammo_Box_Open`（`guaranteed="ammo"`）。
枪里的余弹在撤离时写回 `RaidSim.ammo`，战役结算的武器行能看到「弹匣 / 备弹」。

## 四、手感与规则

**瞄准与命中**

* 朝向沿用玩家原有的鼠标朝向（`facing`，已做 y 压缩补偿）；子弹从「胸口高度」射出
  （`player.global_position + (0,-40)`），目标也按胸口高度判定，避免脚下偏移变成固定偏斜。
* 命中判定是解析射线：沿弹道取每个活体的投影距离 `t` 与垂距 `perp`，
  `perp ≤ HIT_R`（清杀兵 0.46m / 狂暴者 0.52m / 半人 0.40m）且 `los_clear(mask=1)` 才算中。
* 子弹只被物理层 1（墙 / 车厢 / 大件）挡住；沙袋是层 2（低矮掩体），**挡视线不挡子弹**。
* 每颗弹丸单独判定（双管 6 颗），各自画曳光 / 血雾 / 火花。

**噪声：枪是花钱买路**

* 开枪 `emit_noise(pos, noise, "gun", true)`：只画声纹、不放默认枪声（改用这支枪自己的音色），
  半径内 80% 的清杀兵直接 `alert_to(玩家位置)` —— 打一枪，整片巡逻朝你压过来。
* 步枪 44m 的噪声几乎等于「全图通报」；双管 38m；手枪 26m 还能赌一把。
* 撬棍只有 4.5m，而且走的是 `step` 声纹：安静，但贴到 1.9m 内才够得着。

**敌人的血与死**

* `NightSoldier` 新增 `hp = 100` / `dead` / `hit()` / `die()` / `is_alive()`：
  中弹立刻转 `alert`（他知道你在哪），血打空变尸体 —— 不再抓人、不再开枪、贴图渐渐暗下去。
* 打死清杀兵：`conscience -= 0.5`，附近 34m 内的同僚会朝尸体压过来（`on_soldier_killed`）。
* 狂暴者：撬棍 3 下 / 手枪 3 枪 / 莫辛 1 枪。**亲手**放倒算 `rabid_kills`（与「借刀杀人」分开记账）。
* 半人：用武器打死也算灭口 —— `tally += 1`、`conscience -= 10`，且不会因为走过抉择面板而重复记账。

**空仓 / 装填 / 换枪**

* 空仓扣扳机 → 「咔」一声并自动开始装填；`R`（`reload` action）任何时候都能装填。
* 装填时不能开枪；换枪会打断装填。
* `1~4` 换家伙，只切已经到手的槽位；HUD 的档案牌里直接标出 `[2·ТТ-33]` 这种「当前」记号。

## 五、关卡改动（「别的灰盒」）

只动数据，不动 `.tscn`（场景由 `build_scene.py` 重建）：

* **西站调车场（marshalling）**
  * `Sandbags` 沙袋哨位放在驼峰道砟肩（33.0, 9.2）：站在后面能架枪打 1 道那头，蹲下挡视线。
  * `AmmoBox` 弹药箱在调度塔下（24.2, 5.6，`guaranteed="ammo"`）—— 目标是那张发车令，回头就能补弹。
  * `WeaponRack` 枪架在机车库门边（12.4, 4.1），空钩子：说明这地方的人已经把枪拿走了。
* **松林庄园（manor）**
  * `Sandbags` 在焚化院前（27.0, 12.6），和停着的叉车一起构成两个掩体。
  * `AmmoBox` 在卫兵哨位（21.0, 6.2）；`WeaponRack` 在 409 批托盘旁（9.2, 4.2）。
* **货场（yard）** 保持原样 —— 它是「已出图」的基准版本，本轮一张旧图都没重画。

## 六、HUD / 世界读数

* 左上档案牌新增一行：`ТТ-33 手枪 · 6 / 16` + 槽位表 `1·撬棍 [2·ТТ-33] 3·莫辛`；
  空仓时整行转琥珀色并提示 `空仓 · R 装填`，装填时显示 `装填中…`。
* 底部电传条的默认提示补上 `左键 攻击　R 装填　1~4 换家伙`。
* 世界空间（`NightOverlay`）：
  * 枪械：鼠标准星（四段准星，间距随这支枪的散布变化）+ 装填进度环。
  * 撬棍：挥击时在身侧扫过一道弧。
  * 曳光（0.07s）、弹着火星 / 血雾、旋转下落的弹壳、命中标记
    （白黄 = 命中，红 = 击杀）。
  * 死掉的清杀兵不再显示 `!` / `?` 读数。

## 七、操作

| 键 | 作用 |
|---|---|
| 左键 / `Space` | 攻击：撬棍挥击（按住可连挥）/ 枪械单发 |
| `R` | 装填（空仓时扣扳机会自动装填） |
| `1` `2` `3` `4` | 换家伙（撬棍 / ТТ-33 / 莫辛纳甘 / 截短双管，只切已到手） |
| `F5` | F2 独立跑时重开（**原来的 `R` 重来让位给装填**） |

## 八、验收

`tests/night_combat_smoke.gd`（headless，可直接在 CI 里跑）：

```bash
Godot_v4.7.2-stable_win64 --headless --path godot_project -s tests/night_combat_smoke.gd
```

覆盖：军械库表与资产存在性 / 开场装备（撬棍必在、默认掏枪）/ 换枪槽位 / 装填扣备弹 /
撬棍扇形命中（含「背后的打不到」）/ 三棍放倒狂暴者 / 开枪扣弹 + 曳光 + 声纹 + 巡逻被惊动 /
冷却与空仓 / 清杀兵掉血与死亡（同僚压过来、尸体不再抓人）/ 弹药补给与上限。

**实机首跑时请肉眼确认**：

1. 握枪时武器精灵的朝向与翻转（左右各看一次），枪口焰是否在枪口而不是脚下。
2. 沙袋挡视线但不挡子弹：站在沙袋后开枪能打死对面的人，蹲下时探照灯扫不到。
3. 打死清杀兵后，附近的同僚是否真的朝尸体方向过来（声音 / 状态）。
4. 三张图的弹药箱都能搜出步枪弹，且 HUD 的 `备弹` 会涨。

## 九、下一步（没做的）

* 武器在手时没有新的角色动画帧（现在是把武器精灵挂在角色旁边转），需要 `CHR_01` 增加「持枪」
  与「挥击」两行帧。
* 换弹动作、上膛拉栓、弹壳落地的碰撞音都还是「一声音 + 一个精灵」。
* 枪械的准星没有做「命中提示音」，也还没有后坐力导致的准星扩张曲线（只有固定散布）。
* `gym.tscn`（5 合 1 灰盒）是纯 `_draw()` 渲染，本轮没有把新道具塞进去；如果要在灰盒场里
  打靶，得给它加一层精灵层，或者把 `PRP_Target_Silhouette` 直接画进 `Gym.gd` 的 `_draw()`。
