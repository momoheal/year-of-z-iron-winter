# Z年纪事 · 第四幕《3 号矿坑》场景美术设计与接入（L07M）

> 2026-11 · v4.2 新增幕的**第一张场景美术**：温压爆破作业面（`levels/mine.py` → `scenes/night_mine.tscn`）。
> 一句话：**这张图的美术只讲一件事——灰鳞病是他们自己炸出来的，而他们正准备把山和人一起炸掉。**
> 风格依据：`assets/concept_art/ART_STYLE_REFERENCE_v4.2.md` + CON_01（灯光脚本）+ CON_08（矿坑主视觉）+ 总剧本 v4.2 第四幕场次 4-1 / 4-2。

## 一、场景定位（设计锚点）

| 项 | 内容 |
|---|---|
| 剧本锚点 | 总剧本 v4.2 **第四幕**场次 4-1「炸穿的冻土与会发光的粉尘」、场次 4-2「铝热剂阵列与抉择 E」 |
| 关卡代号 | **L07M**（时间线在 L07 松林庄园 与 L08 大火 之间，决战前 48 小时） |
| 玩法定位 | 矿坑潜入关：没有探照灯网，黑暗本身是掩护，也是杀机；三方潜行退居二线（1 组换岗队 + 2 只感染者 + 1 名回退半人），主威胁是**环境** |
| 关键物资 | **intel**（孢子岩芯与爆破台账——第六幕广播的物证，对应抉择 E1） |
| 叙事意象 | 温压爆破炸穿的永冻层断面（灰黑孢子粉尘层）、码放整齐的铝热剂、起爆器、假人哨塔第二座、留守技术员博伊科（回退半人） |
| 撤离 | 南侧铁丝网豁口 · 运矸专线（出生点在黑区——「从黑区往里摸」的开局，同调车场） |

**剧本-美术一致性纪律**（对齐《美术风格参考 v4.2》）：

1. 孢子粉尘是**地质灾难**不是魔法：画成冻土剖面里的灰黑粉尘层，暗哑微光，绝不做「发光魔法阵」；
2. 铝热剂装药**码放得越整齐越可怕**：军绿木箱、电缆敷设到位，是制度化的杀戮；
3. 假人哨塔是**空壳**：远看是防线，近看是塑料模特 + 扩音器——画到「能看清是模特」的程度；
4. 博伊科是**回退期半人**（02 号图规范：鳞屑剥落、瞳孔回色、神情还是人），不是狂暴者；
5. 暖色纪律：全图暖色只出现在七处——斜井洞口、绞车房小窗、两处火堆、工棚窗、两盏钠灯
   （红色另计：信号机 + 仓顶警示灯）。**暖色出现即代表「有人在值守邪恶」**，不温馨。

## 二、色彩脚本与光照设计（对齐 CON_01）

### 2.1 色板（写进 Prompt 与程序化生成的 hex）

| 用途 | hex | 说明 |
|---|---|---|
| 夜空 / 岩壁暗部 | `#0b0f14` / `#232a31` | 顶部压暗融进夜空（与前三关同一套 `_darken_top` 算法） |
| 岩层主体 | `#4a545e` → `#5d6670` | 冷灰蓝，层理横纹（千层糕式冻土剖面，CON_08 的形） |
| **孢子粉尘层** | `#3c4046` + 暗哑微光 `#7d8a72`(0.22) | 灰黑偏绿的死色；微光只在断面凹处，越深越亮一点点 |
| 雪 / 雪檐 | `#d8e1ea` / `#b8c6d4` | 与 yard 同一雪色，不另起色系 |
| 钢构 / 矿车 | `#4e555c` + 锈 `#5b3a26` | 锈水流痕（`rust_streaks`） |
| 井口钠灯暖光 | `#f08a3a`（glow）/ `#ffb35a`（光核） | 全图最暖的一块，泼在井口前的雪地上 |
| 火堆光 | `#ff9e52` | 夜里唯一的「人的温度」 |
| 铝热剂军绿 | `#5c6b4e` + 白色骷髅标 `#d8d1bf` | 与清杀队防化绿呼应：同一个制度的绿 |

### 2.2 光照清单（`LIGHT_RIG` 顺序 = .tscn 节点顺序）

| 灯位 | 类型 | 位置（米） | 色温 | 设计意图 |
|---|---|---|---|---|
| `facade_glow` | 立面窗光贴图 | 全宽 | 混合 | 井口钠灯（暖橙大扇形）+ 工棚窗（暖黄）+ 井架警示灯（红）+ 断面孢子微光（灰绿） |
| `lamp_west` / `lamp_east` | 钠路灯（带影） | (6.0,4.4)/(40.0,4.4) | 暖橙 | 装卸台两头，值班巡逻的照明 |
| `brazier` | 火堆（回温点 1） | (14.5,13.2) | 橙 | 装药队的火：暖色 = 有人在干活（干的是炸山的活） |
| `brazier_cut` | 火堆（回温点 2） | (32.2,25.6) | 橙 | 看守断面的火：博伊科蜷在起爆器旁——**玩家先看见火，才看见人** |
| `signal` | 信号机红灯 | (20.0,12.0) | 红 | 运矸专线的尽头信号——红灯常亮，像给整张图盖了个「禁行」章 |

* **无探照灯**（`SEARCHLIGHT = None`）：黑暗是这张图的第一属性。假人哨塔不发光——远看吓人，近看是空壳，与 1-4 场次的意象闭环。
* 天光：`CanvasModulate (0.27,0.32,0.45)` + `night_post` 冷调分级，与前三关一致；孢子区不加额外滤镜（「越少越真」）。

### 3.1 三带（ZONES）—— 矿坑版的白 / 红 / 黑

| 带 | y 范围 | 语义（离「有人管」越远越黑） | 规则 |
|---|---|---|---|
| 白区 | 0 – 11 | 装卸台：换岗队盯着的地方 | safe：不刷感染者、不被搜 |
| 红区 | 11 – 21 | 工业广场：假人哨塔 + 换岗巡逻 | curfew：不能停 |
| 黑区 | 21 – 34 | 爆破作业面：证据、铝热剂、博伊科 | sunken：感染者成组、每容器多翻一件 |

* 出生点在黑区（同调车场「从黑区往里摸」），但**目标物（起爆器旁的岩芯与台账）也在黑区**——这张图的冒险不是「越深越肥」，而是「证据就在最脏的地方」。

### 6.2 验收标准（check_levels + 目测）

- [x] `check_levels.py` 四关 PASS（mine：spec 字段 / manifest 键 / 场景组数 / metadata / 镜头边界 / CampaignData 接线）
- [x] 三个区的分界（0–11 / 11–21 / 21–34）与《三区与黑市》规则一致；出生点落在黑区
