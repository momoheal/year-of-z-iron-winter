# Z年纪事 · 苏联化界面与关卡节拍（v4.1 前端 / 地图可玩性）

> 本文档记录一次**只动前端与地图呼吸**的迭代：三张节点化夜潜地图（yard / marshalling / manor）
> 共用一套「铁冬」界面系统，并把「这张地图怎么弄死你」写进数据表。
> 不改玩法数值、不新增美术资产、不改 `.tscn`。

## 1. 为什么是「厚重」而不是「花哨」

苏联重工业的视觉语言不是装饰，是**材料与制度**：

1. **材料**：钢板、铆钉、生铁、沥青。所以界面没有圆角、没有渐变高光、没有半透明磨砂；
   面板是「一块铁」压在另一块铁上，靠 **1–2px 的双线 + 留白** 分层。
2. **制度**：档案号、红章、问询单、电传机、保密等级。所以界面上真正「亮」的东西很少：
   一条红章、一枚黄铜表尺、一行电传绿 —— 其余全是骨白与铁灰。
3. **气候**：−30℃。所以读数会掉格、会闪、会结霜；屏幕边缘会结暗角，警报时整块屏幕发烫。

这套东西一旦写成**唯一数据源**，后面所有界面（基地 / 地图 / 夜潜 / 灰盒场 / 结局）就自动统一。

* `mono_font()`：JetBrains Mono → Cascadia Mono → Consolas → DejaVu Sans Mono → Courier New → CJK 兜底
* `body_font()`：Noto Sans CJK SC → Noto Sans SC → 思源黑体 → 微软雅黑 → 黑体 → 苹方

文本工具：`bearing_line()`（八方位 + 米）、`clock()`（mm:ss 电传钟）、`danger_pips()`（▲▲▲△△）、
`tally_glyphs()`（卌 划痕）、`night_zh()`（第三夜）、`pct()`。

* **目标 / 撤离方位**是八方位 + 米数，每帧跟随；目标点由「**必出 `prize` 的容器**」反查
  （`_find_objective_point()`），拿齐关键物资后自动切成「回撤离点」。世界里 18m 内会点亮
  `ЦЕЛЬ · 目标物资` 光圈（`NightOverlay.gd`）。
* **勘踏进度**给出「最近未勘地标的方位 + 距离」——把「逛地图」变成一条可读的线。
* 中央读数（被发现 / 冻死 / 天亮 / 撤离成功）用钢印体 + 8px 黑描边；抉择面板是一张
  `ОПРОСНЫЙ ЛИСТ`（问询单）。
* `CampaignHUD.gd` / `GymHUD.gd` / `HUD.gd` 全部改走同一套工厂，并按上表整表替换了旧的 slate 蓝绿配色；
  战役标题页变成案卷封面（`ЖЕЛЕЗНАЯ ЗИМА` + 斜盖 `СЕКРЕТНО` 章）；地图节点卡新增「环境档案」块。

## 5. 关卡档案层（`scripts/night/LevelBeats.gd`）

三张图共用 `NightExplore.gd`，差异全在数据表里。每个关卡一条记录：

```gdscript
"marshalling": {
    "scene":  "res://scenes/night_marshalling.tscn",
    "code":   "ДЕЛО № 1100 · ЗАПАДНЫЙ ПАРК",
    "zone":   "НОВОРСК-17 · ЗАПАДНЫЙ СОРТИРОВОЧНЫЙ ПАРК",
    "danger": 4,
    "accent": Color("8c7139"),
    "brief":  ["五股道在脚下分开……", "驼峰那头每隔一会儿就放一辆车皮下来 —— 别站在股道上。"],
    "landmarks": [ {name, pos:[x,y](米), radius, note}, … ],
    "events":    [ {kind:"hump", period:30, warn:2.6, live:3.0, lane:15.6, lane_alt:20.2,
                    from:43.0, to:1.0, shove:2.2} ],
    "mechanisms":[ {kind:"switch", node:"World/Props/SwitchStand01", …} ],
    "first_beat": 22.0,
}
```

### 5.1 环境节拍

导演状态机：`""`（等待）→ `warn`（预警，给玩家反应窗口）→ `live`（发生，逐帧判定）→ 收尾 → `period` 后下一拍。

| 关卡 | 节拍 | 预警 | 发生 | 判定 | 玩家应对 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **marshalling** | 驼峰溜放 `hump` | 2.6s（远处汽笛 + 电传提示 + 右栏环境警报） | 3.0s：一辆车皮沿 2 道 43m → 1m 滑过（暗剪影 + 车灯 + 每 0.34s 一次轮轨声） | 与车皮横向距离 ≤ 2.2m 且站在该股道 ±1.15m → 刮倒：−9 HP / −6 体温 / 12m 巨响（引狂暴者） | 提前离开那股道；或 **E 扳道岔** 把溜放改到 3 道 |
| **manor** | 炉口爆燃 `flare` | 2.4s（炉膛发白 + 闷响） | 1.6s：补光灯顶到 3.4 能量、后处理 `alarm` 抬红、镜头轻震 | 在炉口 22m 内且视线未被 layer-1 遮挡（松树 / 车皮 / 钢管 / 墙）→「影子被钉在雪上」：34m 内特勤直接 `alert_to()`，10m 声纹（静音）引狂暴者；蹲下且躲在**低矮掩体**（layer-2）后也算安全 | 蹲进松林 / 车皮背后；或干脆别在炉口那半边院子 |

> 为什么不做伤害数字弹窗：爆燃与溜放都是**环境**，压迫感来自光、声、和「你刚才站错地方了」，
> 所以只给一行浮字 + 屏幕发烫 + 震屏。

### 5.2 专属机关（靠近按 `E`）

| 关卡 | 机关 | 效果 |
| :--- | :--- | :--- |
| marshalling | 1 号 / 2 号转辙器 | 切换驼峰溜放股道（主 2 道 ⇄ 备 3 道）；扳动本身发出 7m 金属巨响（会引来东西） |
| manor | 停着的叉车 | 一次性：16m「巨型罐头」，把敌我全引过去（`forklift_used` 之后不再提示） |

### 5.3 地标勘踏

走近半径 → `sfx.beep` + 世界浮字「勘踏 · ×××」+ 一行档案注解；右栏累计 `勘踏 n/m`。
地标不是收集品、不给物资：它奖励的是**看懂这块地方**（哪节车厢是拉娜的、哪盏灯是调度塔的）。

| 关卡 | 地标 |
| :--- | :--- |
| yard | 三号闷罐车厢 · 锅炉房通风口 · 油桶火堆 · 水泥游乐穹顶 |
| marshalling | 调度塔 · 驼峰溜放线 · 煤水塔 · 南侧涵洞 |
| manor | 二号恒温库防爆门 · 2000℃ 炉口 · 二楼行政钢廊 · 冻观赏池 · 西侧松林 |
