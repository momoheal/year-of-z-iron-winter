## 一、这一版补上的是「循环」，而不是又一个房间

灰盒测试场证明的是**单个机制**能玩：借刀杀人、卡门推饭盒、抉择 A 与卌、狼犬三态、锁骨卡刀 QTE。
Exploration Demo 证明的是**一整夜**能玩：

```
标题 → 602 室（基地） → 城市地图选点 → 夜潜（程序化街区 + 搜刮 + 遭遇）
     → 撤离 / 天亮 / 倒地 / 放弃 → 结算 → 次日（母亲透析） → 回到基地
```

本次把这套循环整体搬进 Godot，并保持：

* **数值同源**：所有常量直接来自 HTML 的 `CFG` / `ITEMS` / `WEAPONS` / `MATES` / `LOCS` / `STORY`；
* **状态同源**：`卌` 划痕、真名、良知、母亲腹透液、武器收集度、13 个地图节点余量全部由 `CampaignSim` 单一持有；
* **渲染同源**：`_draw()` 立即模式，26 px/米 + y 轴 0.62 压缩的 75° 斜俯视，零美术资产；
* **跨场景同源**：`LogbookManager` autoload 继续把真名与划痕同步到灰盒场 / Room A 切片。

## 四、逐机制对照

### 1. 城市地图与 13 个节点

* 地图坐标沿用原型的 `900 × 520` 平面，`Campaign.gd` 在 `MAP_RECT` 内直接以 1:1 绘制，鼠标点选半径 62 px。
* 节点解锁三条件：`req_flag`（`manor_tip` / `lana_car3`）→ `req`（`intel ≥ 2` + `med ≥ 1`）→ 无门槛。
  开局 **10/13** 解锁；疗养院、松林庄园、西站调车场分别被门槛锁住。
* 每个节点记录 `visits` 与 `left`（容器余量）：踏足一次 `left = clamp(left − 0.5, 0.05, 1.0)`，所以同一个地方第二夜只剩一半箱子。

### 2. 程序化街区生成（`RaidGen.generate`）

顺序与原型一致，且**同 seed 同图**（`seed = 地点 seed + 天 × 7`）：

1. 主街（4–5 米宽，横 + 竖各一条）与 1–2 条支路，带间距 ≥ 4；
2. 街道带之间切出扇区（≥ 4×4），逐扇区铺地板；
3. 每个扇区最多 3 栋**可进建筑**：门开在朝向街道的一格，40 次尝试，失败则回滚墙体并检查扇区连通；
4. 1–2 栋实心楼（同尺寸回滚 + 连通检查）；
5. 扇区中心螺旋寻找干净空地作为「房间锚点」，并抽一个机械特征（储藏/冷柜/黑暗/厨房/诊所/巡逻/车间/无）；
6. 雪泥团（半径 1–2，62%）、掩体条、铁丝网条、1 米窄口的门（30%）；
7. 容器（容器数由危险度与余量决定，建筑内倾向冷柜/木箱，街上倾向配给箱/垃圾箱）；
8. 火堆：`cold > 1.0` 的地点 2 堆，否则 1 堆；厨房房间额外一堆；
9. `ensure_connected()`：从入口泛洪，把孤立的地板区凿通（建筑内部受保护）；
10. 边界环：6–13 格一段，55% 建筑 / 45% 围墙。

`tests/campaign_smoke.gd` 用「同 seed 网格逐字节相等 / 跨天不等 / 所有容器可达 / 可达地板 > 400 格」固定这些性质。

### 3. 视野、雾与光锥

* 逐瓦片可见性：距离 ≤ 12m（碎镜 7.2m）、1.8m 内无条件可见、其余要求 90° 视锥 + `los_clear`（墙 / 焊死门 / 卡住的门阻断）。
* 三态绘制：**未探索**（纯黑）→ **已探索但当前不可见**（55% 压暗）→ **可见**（原色 + 视野多边形柔光）。
* 视野多边形 55 条射线 × 0.35 米步进，遇 `blocks_sight`（墙 / 卡住的门 / 掩体 / 焊死门）截断。

### 4. 移动、噪声与借刀杀人

* 手动碰撞：6 个采样点（左右 + 上下各 3）查 `blocks_move`（墙 / 掩体 / 铁丝网 / 卡住的门 / 焊死门）。
* 移动距离累积到 0.9 米（潜行）或 1.4 米（走/跑）时发一次噪声波纹；雪泥上半径翻倍。
* 清杀兵（O.S.K.）听到 ≤ 16m 内半径 ≥ 2 的噪声后转入 `investigate`，走向声源。
* 清杀兵 22.5° 半光锥 + 14m 内发现玩家 → `suspect` 累积；`lock` 满 1 秒开火（命中率 `1 − d/14`，下限 25%，再 ×0.75，18 伤害）。
* **借刀杀人**：光锥内出现狂暴者 / 半人时 0.5 秒后开火——狂暴者被清掉时记 `killed +1`，半人被杀则良知 −3 并记一条 `witness` 事件。

### 5. 体温、心率与生命

* 体温衰减 = `地点 cold × 0.55`；雪泥 ×1.5、潜行 ×0.85、冷柜房间 ×1.6；火堆 2.6m 内 +30/s。
* 体温 < 25 时按差值扣血；< 30 弹一次提示；> 45 复位提示。
* 心率目标 = `70 + 冲刺 34 + 重伤 22 + 恐惧 26 + 失温 12`，用 `lerp(…, 1 − 0.02^dt)` 平滑——与原型同一公式。
* 诊所房间一次性 +25 HP。

### 6. 搜刮与战利品

* 搜刮 1.7s 长按，完成后：容器标记已搜、`looted +1`、逐件入包（满 12 即「留在原地」并提示）。
* `gen_loot` 规则：保险柜 3 / 暗格 2 / 尸体 2 / 其它 1，另有 42% +1；62% 走容器类型池、否则走地点池；
  `part|weapon` 62% 退化为废钢；`med` 55% 直接给绷带（见「刻意偏差」）；暗格 50% 追加一袋腹透液。
* 古丽娅：医疗柜 / 冷柜产出 ×1.5。

### 7. 卡门、破门与撤离

* 撬棍对门（`TT_DOOR`）按住 E 1.2s → 变为 `TT_WEDGED` 并写入 15 秒计时；计时到点自动弹回 `TT_DOOR`（若仍是卡住状态）。
* 焊死门（`TT_BDOOR`）按住 E 0.8s（帕维尔 0.4s）→ `TT_DOOR`。
* 站在入口 1.6m 内按住 E 1.5s → `extracted`（撤离优先级高于同位置的容器/门）。

### 8. 四种收场与结算

| 收场 | 触发 | 物资 | 额外 |
| :--- | :--- | :--- | :--- |
| `extracted` | 撤离进度满 | 全部 | — |
| `dawn` | 夜计时归零 | 只保留偶数位（0,2,4…） | `HP = max(6, HP − 22)` |
| `downed` | HP ≤ 0（古丽娅每夜可救一次） | 全丢 | — |
| `abort` | Esc → 确认 | 全丢 | — |

结算页（`last_report`）逐项对应原型：带回物资、搜刮 `looted/total`、击杀、救助半人、`HP/体温`、事件流、武器架解锁、日志背面划痕、良知与真名数、母亲剩余腹透液。

### 9. 次日与母亲

`advance_day()`：天数 +1 → 若库存有 `dial` 则消耗 1 袋并把 `dial` 顶到 3；否则 `dial −1`，`dial ≤ 0` 时母亲去世、`mother_lost = true`、良知 −10。

### 10. 剧情节拍与抉择 A

* 7 段节拍（coldstore / yard / canteen / sanitarium / market / marshalling / 结局前）以数据驱动 `ops`：
  `["add", id, n]`、`["take", id, n]`、`["conscience", d]`、`["tally", n]`、`["flag", id]`、`["mate", id]`、`["name", str]`，外加 `after_mate`（冷库 → 灰烬、食堂 → 帕维尔、黑市 C3 → 伊万）。
* 节拍只在第一次进入对应地点时弹出（`story_done` 保护，不可重放）。
* **抉择 A**（野地里的半人）：A1 喂药退烧（消耗阿司匹林 + 热水各 1，良知 +7，半人 +1，得暗号）；A2 绕行（良知 −2，身后枪声）；A3 撬棍灭口（卌 +1、良知 −10、`betrayed`）。

### 11. 目标与结局

`objective()` 按 `names` → `lana_car3` → `endgame_known` → 松林庄园 四段推进；
`ending_key()` 判定：真结局 α（母亲存活 + 零划痕 + 真相 + 未背叛） / 真结局 β（真相在手） / 结局 B（划痕 > 0） / 结局 C（没有真相）。

## 五、刻意偏差（6 项，均为修正而非改设计）

| # | HTML 原型 | Godot 实现 | 理由 |
| :--- | :--- | :--- | :--- |
| 1 | `genLoot` 里 `cat='band'` 在 `CAT` 表里不存在，实际退化成废钢 | 直接产出绷带 | 原型明显是笔误；医疗池应给医疗物资 |
| 2 | 节拍弹窗不做「已看过」保护，重复调用 `resolveStory` 会二次结算 | `story_done` 命中即返回空 | 防止 UI 误触重复加良知 / 真名 |
| 3 | 半人在光锥内被杀只扣良知 | 额外写一条 `witness` 事件进结算流 | 让「看着别人被杀」在日志里留痕 |
| 4 | 卡刀 QTE 没有失败结算 | 超时 −22 HP + 「被带倒在地」浮字 | 原型注释已写明后果，补上数值 |
| 5 | 抉择 A1 缺药时可以无限重复弹窗 | 缺药弹一次提示后置 `choice_denied`，带齐药后自动解锁 | 避免按住 E 反复打断 |
| 6 | 伙伴在 HUD 里只是数据 | 灰烬 7m 内狂吠（噪声 3.0）、古丽娅复活一次、安娜 +4 格、帕维尔破门减半、伊万标暗格 | 原型 `MATES` 文案中的能力落到实际判定 |

> 除此之外，**所有阈值、半径、时长、伤害、概率都与原型逐行对齐**，并由 97 项断言固定。
