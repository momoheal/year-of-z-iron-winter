# Z年纪事 · 三区与黑市（白 / 红 / 黑）

> 2026-11 · 夜潜五张图（L03 货场 / L04 调车场 / L05 庄园 / L07M 矿坑 / L07 铁路黑市）统一改成「三个区」。
> 一句话：**离白区越远，丧尸越多、东西越好、规矩越少。**

---

## 一、为什么这么切

原来的地图只有「危险度 ▲▲▲△△」一个模糊概念，玩家不知道走到哪一步算越线。
现在按**离白区（居民区）的距离**切成三条带，每一带自己有一套规则：
白区是玩家出发的地方，红区是白区居民的禁区，黑区是没人管的地方 —— 也是唯一值得冒险的地方。

| 区 | 位置 | 丧尸 | 资源 | 清杀队 | 玩家 |
|---|---|---|---|---|---|
| **白区** WHITE | 楼前院子 / 调度楼前 / 庄园装卸场 | 0 | 常规 | 不进来 | 居民区，可以放心走 |
| **红区** RED | 白区外围，到铁丝网 / 股道为止 | ≤ 3 | 常规 | 巡逻（主力） | **白区居民禁止进入** |
| **黑区** BLACK | 铁丝网以南：货场 / 车皮区 / 松林 | 7~8 | 每个容器多翻一件 | 只在边上晃，基本不管 | 黑市与幸存者在这里 |

三张图的分界线（米，y 向南为正）：

| 关卡 | 白区 | 红区 | 黑区 | 出生点落在 |
|---|---|---|---|---|
| L03 货场 `night_explore.tscn` | 0 ~ 12 | 12 ~ 21.5（铁丝网） | 21.5 ~ 40 | 白区（锅炉房通风口） |
| L04 调车场 `night_marshalling.tscn` | 0 ~ 9 | 9 ~ 20 | 20 ~ 36 | 黑区（涵洞） |
| L05 庄园 `night_manor.tscn` | 0 ~ 10 | 10 ~ 22 | 22 ~ 38 | 黑区（电网外） |
| L07M 矿坑 `night_mine.tscn` | 0 ~ 11（装卸台） | 11 ~ 21（工业广场） | 21 ~ 34（爆破作业面） | 黑区（南侧豁口外） |
| L07 铁路黑市 `night_market.tscn` | 0 ~ 11（镇口街） | 11 ~ 21（棚户巷） | 21 ~ 34（市集与铁路侧） | 白区（镇口街） |

> 庄园和调车场是「从黑区往里摸」，货场是「从白区往外走」—— 两种开局都存在，但三条带的关系不变。
> 矿坑的三条带是「离有人管的地方越远越黑」：白区是换岗队盯着的装卸台，红区是假人哨塔 + 巡逻的工业广场，
> 黑区是爆破作业面——**出生点和目标物都在黑区**（无探照灯：黑暗是这张图的第一属性）。
> 黑市的老家（market 关）三条带的轴是「离摊主规矩区的距离」：白区是规矩牌下的镇口街（可以站定了搜包），
> 红区是互不信任的棚户巷（不能停），黑区是市集深处与铁路侧——**摊区就是黑区的中心**（见「四、黑市」）。

## 二、规则

### 白区 · 安全区
- 不刷丧尸；清杀队不会进来搜你。**唯一能站定了搜包的地方。**
- 仍然会被听见：白区开枪照样有噪声，只是没人来救你。

### 红区 · 管制带（白区居民禁止进入）
- 进区 3.5 秒：屏幕提示「红区 · 白区居民禁止进入」，一声短促电子音。
- 继续待 7 秒：最近的清杀兵被叫过来盘问（`alert_to` + 电台声 + 晃屏），提示「管制带 · 出示通行证！」。
- 所以红区不是不能过，是**不能停**：跑过去，别在灯下站着。
- 丧尸 0~3 只：管制带靠人管，不靠尸群。

### 黑区 · 沉降带
- 丧尸 7~8 只，成组分布，巡逻半径大。
- 每个容器**多翻一件**（`NightZones.loot_bonus`）—— 好东西都在这一带。
- 黑市与幸存者只在这里：那是「和白区断干净了的人」才待得住的地方。

## 三、画面怎么读

地面按区淡淡染一层，上沿一条虚线，地面上压一行英文标签：

- 白区：冷白（`#9fc6e0`，透明度 0.075）· `ZONE A · SAFE`
- 红区：赭红（`#c8483a`，0.115）· `ZONE B · CURFEW`
- 黑区：深青（`#3aa0b4`，0.165）· `ZONE C · SUNKEN`

色带画在**地面之上、所有立起来的精灵之下**（`z_index = -1`），所以道具、人物、灯光的颜色都不受影响 ——
它只是「地面在告诉你这是哪个区」。HUD 的档案牌上还会多一行：

```
所在区  红区 · 管制带  ·  禁止进入（白区户口）
```

## 四、黑市（黑区）

每个关卡一个，都在黑区：

| 关卡 | 位置（米） | 挨着什么 |
|---|---|---|
| 货场 | (26.5, 24.2) | 铁丝网豁口以南 3 m，过了网就看见那盏灯 |
| 调车场 | (33.0, 29.6) | 东南角那盆火旁边 |
| 庄园 | (11.8, 27.4) | 西松林那堆木箱旁 |
| 矿坑 | — | **没有黑市**：黑市是居民点的生意，不是作业面的（L07M 环境杀关） |
| 铁路黑市 | (24.5, 24.4) | **这就是黑市的老家**——摊区是这张图的正中心（黑区 21~34 m 的正中），周围还有假药摊、6.66 电台棚和烫鳞后巷 |

- **一罐罐头 = 8 发**，只换你已经有的枪（步枪 → 锯短 → 手枪依次），**一夜一次**。
- 罐头本来是引丧尸的饵 —— 黑市把「拿它换命」和「拿它换子弹」变成一道真的选择。
- 摊位 = 拼板桌 + 两只弹盒 + 一罐罐头 + 杆子上的马灯（`PRP_Market_Stall`），引擎里再加一盏 `PointLight2D`。
- 摊主 `PRP_Trader_Stand`（红袖标 + 马灯）、幸存者 `PRP_Survivor_Stand`（灰褐棉袄 + **白袖标** = 白区户口）。
  他们都是静态立绘、**没有碰撞**：玩家能从人身上穿过去，不会被卡在摊子前。走近会说一句话。

## 五、火苗（油桶）

之前火苗整簇 84 px、顶端顶到油桶落地点上方 130 px —— 桶身才 54 px，火比桶高一倍多，看着像烧到墙上。

现在：火苗纵向压到 0.42、横向 0.58，顶端 **91 px**，火只从桶口往上蹿 35 px。火星粒子也一起收小（26 → 20，寿命 1.6 → 1.3 s）。

`tests/night_zones_smoke.gd` 的 `[fire]` 段把这条写成了硬断言：`flame.scale.y ≤ 0.5` 且顶端 ≤ 100 px。

## 六、尸群配置（可直接数）

| 关卡 | 白区 | 红区 | 黑区 | 合计 |
|---|---|---|---|---|
| 货场 | 0 | 2 | 8 | 10 |
| 调车场 | 0 | 3 | 7 | 10 |
| 庄园 | 0 | 1 | 7 | 8 |
| 矿坑 | 0 | 1 | 1 | 2 |
| 铁路黑市 | 0 | 0 | 2 | 2 |

红区里那两三只都是「被赶出来的」：写在关卡文件里，名字和位置都带解释
（`Rabid_Car` / `Rabid_Hump` / `Rabid_Kiln` …），黑区的是成组的（道砟、信号机下、煤棚、东南角）。
矿坑是「环境杀」关：危险来自塌方 / 粉尘窒息 / 起爆倒计时 + 清杀队换岗——
两只感染掘进工（`Rabid_Cart` / `Rabid_Cut`）只是孢子源头的注脚，`night_zones_smoke.gd`
用 `LEVEL_RULES` 把这座图的尸群下限单独放宽（black_min 1 / red_max 1 / 无黑市）。
铁路黑市是「人杀」关：危险来自交易、辨药与抉择 C（人会开枪，但比清杀队讲道理）——
铁轨上的两只感染者（`Rabid_Rail` / `Rabid_Alley`）只是注脚，`LEVEL_RULES["market"]`
放宽到 black_min 2 / red_max 1 / **有黑市**（摊区就在黑区中心，烟测的「黑市在黑区」断言原样成立）。

## 七、验收怎么做

1. **看图**：`docs/ui/verify/` 八张整关图上能直接看到三条带（红虚线 = 白/红界，青虚线 = 红/黑界），
   黑区里能看到摊子和人。网页版：`docs/ui/acceptance.html`。
2. **静态体检**：`cd godot_project/tools/art_gen && python3 check_levels.py`（应当 PASS）。
3. **跑测试**（要有引擎的机器）：
   ```
   Godot_v4.7.2-stable_win64 --headless --path godot_project -s tests/night_zones_smoke.gd
   ```
   覆盖：解析器 / 分区铺满无缝隙 / 出生点落在正确的区 / 丧尸分布 / 半人不在白区 /
   黑市在黑区且摊子边上有人 / 红区 3.5 s 警告 7 s 盘问 / 一罐换八发且一夜一次 / 火苗高度。
