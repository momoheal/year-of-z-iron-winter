## 二、故事的因果主轴

阿列克谢为换取母亲卡佳的腹膜透析液，签署或默许了 004 号车皮调拨单；十天后，妹妹拉娜（档案号 0420）被装进铁壳号第三节车厢。阿列克谢先想救母、再寻找妹妹，沿途遇到被账面注销的病人，逐步发现灰鳞高热可自行退去，清杀队仍把康复者当作“已出清”转运、焚毁或销账。疗养院手稿、黑市线路、松林庄园账本和 3 号矿坑证物把“病人是否康复”“配给如何分配”“谁签署/执行了转运”三条线连到一起。鹰嘴崖重逢拉娜后，主角面对是否救第三节车厢、是否公开真相，以及是否承担自己签名责任的终局选择。

**主线关系链：** 004 调拨签名 → 透析液换取服从 → 拉娜成为 0420 → 冷库/疗养院证实病人仍是活人 → 档案与庄园追出转运和药品去向 → 矿坑证据补充病源/爆破线 → 鹰嘴崖确认妹妹与签名的因果 → 302 广播公开姓名与责任 → 结局按救援、真相、良知划痕和母亲状态分流。

**叙事命题：** 制度把活人写成编号或“零”；主角的工作日志反向记下姓名。004 黄铜铭牌和《双面工作日志》是贯穿的物证：前者记录主角参与转运的责任，后者记录他后来是否把人重新写回“活人”。

### 6.2 当前代码可见的关键分支

- **夜潜常驻半人抉择 A（`CampaignHUD.gd` / `RaidSim.gd`）：** A1 需消耗阿司匹林和热水，良知 +7、救下半人并获得老轨暗号；A2 绕过，良知 −2，半人被枪杀；A3 撬棍杀死并搜刮，卌 +1、良知 −10、写入 `betrayed`。这段当前玩法不在文学主稿 1-3 的明示场景分支中；主稿附录却提到“未杀回退半人 A3”，应对齐编号与场景。
- **冷库 `coldstore`：** 救父女并喂狗记名、良知 +8、灰烬入队；离开则不救人、灰烬不入队。
- **货场 `yard`：** 收编组单，情报 +1、扎哈尔入队。
- **食堂 `canteen`：** 只有一刀自卫结果；良知 −4、PTSD、帕维尔加入，但不记卌划痕。
- **黑市 `market`：** 公平交易（废钢换情报）、分抗生素救人（良知 +10、伊万加入）或背叛伊万（大量资源、卌 +1、写入 `betrayed`）；三种都写入 `broadcast_signal`。

### 6.3 当前代码的五个结局判定

`CampaignSim.ending_key()` 的顺序是：

1. 母亲存活 + `truth` + 卌为 0 + 无 `betrayed` → **TRUE α**。
